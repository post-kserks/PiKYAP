# Рубежный контроль №1

**Вариант 18А.** Предметная область: «Музыкальное произведение — Оркестр», запросы варианта А.

## Классы данных

Соответствие классам из примера «Сотрудник — Отдел»:

| Пример | Вариант 18 | Поля |
|---|---|---|
| Сотрудник | `Work` — музыкальное произведение | `id`, `title` (название), `duration` (длительность, мин — количественный признак), `orchestra_id` (связь один-ко-многим) |
| Отдел | `Orchestra` — оркестр | `id`, `name` (название) |
| Сотрудники отдела | `WorkOrchestra` — репертуар оркестра | `orchestra_id`, `work_id` (связь многие-ко-многим) |

## Запросы (вариант А)

1. Один-ко-многим: список всех связанных произведений и оркестров, отсортированный по оркестрам.
2. Один-ко-многим: список оркестров с суммарной длительностью произведений, отсортированный по суммарной длительности (по убыванию).
3. Многие-ко-многим: оркестры, в названии которых есть слово «оркестр» (без учёта регистра), и произведения из их репертуара.

## Запуск

```bash
python3 rk1.py
```
