# Лабораторная работа №1. Основные конструкции языка Python

**Цель:** изучение основных конструкций языка Python.

## Задание

Разработать программы для решения биквадратного уравнения `A*x^4 + B*x^2 + C = 0`:

1. `biquadratic_proc.py` — процедурная парадигма (функции, `def`);
2. `biquadratic_oop.py` — объектно-ориентированная парадигма (классы);
3. `biquadratic_func.py` — функциональная парадигма (сопоставление с образцом, `match/case`, нужен Python 3.10+).

Каждая программа:

- берёт коэффициенты A, B, C из параметров командной строки, а если они не заданы — запрашивает с клавиатуры;
- если значение некорректно (не преобразуется в действительное число), игнорирует его и запрашивает коэффициент повторно;
- вычисляет дискриминант и действительные корни уравнения.

## Решение

Замена `t = x^2` сводит уравнение к квадратному `A*t^2 + B*t + C = 0`, `D = B^2 - 4AC`.
Для каждого корня `t`: при `t > 0` получаем `x = ±√t`, при `t = 0` получаем `x = 0`, при `t < 0` действительных корней нет.
Отдельно разобран вырожденный случай `A = 0`.

## Запуск

```bash
python3 biquadratic_proc.py 1 -5 4
python3 biquadratic_oop.py 1 0 -4
python3 biquadratic_func.py          # коэффициенты вводятся с клавиатуры
```
